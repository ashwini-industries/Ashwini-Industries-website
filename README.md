# Ashwini Industries - Web Application

Modern website and digital portal for Ashwini Industries, manufacturer and exporter of high-quality synthetic food colors, lake colors, and dye intermediates.

## Tech Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Vite, Framer Motion
- **Monorepo**: pnpm workspaces
- **Deployment**: Vercel

## Development
```bash
pnpm install
pnpm --filter @workspace/food-colors run dev
```

## Production Build
```bash
pnpm run build
```
